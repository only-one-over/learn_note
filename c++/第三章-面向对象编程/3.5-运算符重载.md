# 3.5 运算符重载

运算符重载允许自定义类对象使用内置运算符。重载的运算符本质上是一个函数，函数名为 operator 加上运算符符号。可以通过成员函数或友元函数来重载。一元运算符用成员函数重载，二元运算符中如果左操作数不是本类对象则用友元函数重载。

```cpp
#include <iostream>
using namespace std;
class Complex {
double real, imag;
public:
Complex(double r = 0, double i = 0) : real(r), imag(i) {}
// 成员函数重载 +
Complex operator+(const Complex& o) const {
return Complex(real + o.real, imag + o.imag);
}
// 友元函数重载 <<
friend ostream& operator<<(ostream& os, const Complex& c) {
os << c.real << " + " << c.imag << "i";
return os;
}
};
int main() {
Complex c1(3, 4), c2(1, 2);
Complex sum = c1 + c2;
cout << c1 << " + " << c2 << " = " << sum << endl;
return 0;
}
```
