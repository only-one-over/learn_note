# 3.1 类与对象

类（class）是面向对象编程的核心，它将数据（成员变量）和操作数据的方法（成员函数）封装在一起。对象是类的实例。类定义了一种数据类型的蓝图，而对象是根据这个蓝图创建的具体实体。

构造函数在对象创建时自动调用，用于初始化成员变量。C++ 支持默认构造、带参构造、拷贝构造、移动构造和委托构造。析构函数在对象销毁时自动调用，用于释放资源。初始化列表是初始化成员变量的推荐方式，效率高于在构造函数体内赋值。

```cpp
#include <iostream>
#include <string>
using namespace std;
class Student {
private:
string name;
int age;
public:
// 默认构造函数
Student() : name("未知"), age(0) {}
// 带参构造函数（使用初始化列表）
Student(string n, int a) : name(n), age(a) {}
// 拷贝构造函数
Student(const Student& other) : name(other.name), age(other.age) {}
// 析构函数
~Student() { cout << name << " 对象销毁" << endl; }
void display() {
cout << "姓名: " << name << ", 年龄: " << age << endl;
}
};
int main() {
Student s1;                    // 默认构造
Student s2("张三", 20);       // 带参构造
Student s3 = s2;              // 拷贝构造
s2.display();
return 0;
}
```
