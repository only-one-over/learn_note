# 3.2 封装与访问控制

封装是面向对象的三大特性之一，通过访问控制修饰符实现。private 成员只能在类内部访问，public 成员可以在任何地方访问，protected 成员可以在类内部和派生类中访问。封装隐藏了实现细节，只暴露必要的接口。

友元（friend）是封装的例外机制。被声明为友元的函数或类可以访问该类的私有成员。友元打破了封装，应谨慎使用。

```cpp
#include <iostream>
#include <string>
using namespace std;
class BankAccount {
private:
string accountNumber;
double balance;
public:
BankAccount(string num, double bal)
: accountNumber(num), balance(bal) {}
void deposit(double amount) {
if (amount > 0) balance += amount;
}
void withdraw(double amount) {
if (amount > 0 && amount <= balance)
balance -= amount;
}
double getBalance() const { return balance; }
};
int main() {
BankAccount acc("123456", 1000.0);
acc.deposit(500);
acc.withdraw(200);
cout << "余额: " << acc.getBalance() << endl; // 1300
// acc.balance = 0; // 错误: 私有成员不可访问
return 0;
}
```
