# 5.2 智能指针

智能指针是 C++11 引入的 RAII 包装类，自动管理动态分配的内存，在析构时自动释放资源。

unique_ptr

独占所有权的智能指针。同一时刻只能有一个 unique_ptr 指向某个对象，不能拷贝，只能移动。make_unique<T>（C++14）是创建的推荐方式。

shared_ptr

共享所有权的智能指针。多个 shared_ptr 可以指向同一个对象，通过引用计数跟踪所有者数量。当最后一个 shared_ptr 被销毁时，对象自动删除。

weak_ptr

弱引用智能指针，指向 shared_ptr 管理的对象但不增加引用计数。用于解决 shared_ptr 的循环引用问题。使用前需要通过 lock() 方法提升为 shared_ptr。

```cpp
#include <iostream>
#include <memory>
using namespace std;
class Resource {
string name;
public:
Resource(string n) : name(n) { cout << name << " 创建" << endl; }
~Resource() { cout << name << " 销毁" << endl; }
};
int main() {
// unique_ptr - 独占所有权
auto p1 = make_unique<Resource>("A");
auto p2 = move(p1);      // 移动所有权
cout << "p1空? " << (p1 == nullptr) << endl;
// shared_ptr - 共享所有权
auto s1 = make_shared<Resource>("B");
cout << "引用计数: " << s1.use_count() << endl;
auto s2 = s1;
cout << "引用计数: " << s1.use_count() << endl;
// weak_ptr - 弱引用
weak_ptr<Resource> w = s1;
cout << "过期? " << w.expired() << endl;
return 0;
}
```
