# 4.2 迭代器

迭代器（Iterator）是 STL 的核心设计模式，提供了统一的方式来遍历不同类型的容器。迭代器的行为类似指针，支持解引用（*it）获取元素、递增（++it）移动到下一个元素。

迭代器分为五类：输入迭代器、输出迭代器、前向迭代器、双向迭代器和随机访问迭代器。vector 的迭代器是随机访问迭代器，list 是双向迭代器。C++11 的 auto 关键字大大简化了迭代器的声明。

```cpp
#include <iostream>
#include <vector>
using namespace std;
int main() {
vector<int> vec = {10, 20, 30, 40, 50};
// 正向迭代器
for (auto it = vec.begin(); it != vec.end(); ++it)
cout << *it << " ";
cout << endl;
// 反向迭代器
for (auto it = vec.rbegin(); it != vec.rend(); ++it)
cout << *it << " ";
cout << endl;
// auto简化 + 常量迭代器
for (auto cit = vec.cbegin(); cit != vec.cend(); ++cit)
cout << *cit << " ";
cout << endl;
return 0;
}
```
