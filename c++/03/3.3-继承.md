# 3.3 继承

继承允许创建一个新类（派生类）来继承已有类（基类）的属性和行为，实现代码复用和层次化建模。C++ 支持单继承和多重继承。派生类的构造函数会先调用基类的构造函数，析构时则先执行派生类析构函数再执行基类析构函数。

多重继承可能引发菱形继承问题（两个基类继承自同一祖先），可以通过虚继承（virtual inheritance）解决。

```cpp
#include <iostream>
#include <string>
using namespace std;
class Animal {
protected:
string name;
public:
Animal(string n) : name(n) {}
virtual void speak() { cout << name << " 发出声音" << endl; }
virtual ~Animal() {}
};
class Dog : public Animal {
public:
Dog(string n) : Animal(n) {}
void speak() override { cout << name << " 汪汪叫!" << endl; }
};
class Cat : public Animal {
public:
Cat(string n) : Animal(n) {}
void speak() override { cout << name << " 喵喵叫!" << endl; }
};
int main() {
Dog dog("旺财");
Cat cat("咪咪");
dog.speak(); // 旺财 汪汪叫!
cat.speak(); // 咪咪 喵喵叫!
// 多态: 基类指针指向派生类
Animal* a = new Dog("来福");
a->speak(); // 来福 汪汪叫!
delete a;
return 0;
}
```
