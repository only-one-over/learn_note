# 5.4 右值引用与移动语义

右值引用（C++11，用 && 声明）是绑定到临时对象（右值）的引用。移动语义允许转移资源而非拷贝资源，当对象即将被销毁时，可以将其内部资源直接窃过来。

std::move() 函数将左值转换为右值引用。完美转发（std::forward）用于模板中，将参数按原始类型（左值或右值）转发给另一个函数。

```cpp
#include <iostream>
#include <string>
#include <utility>
using namespace std;
class Buffer {
int* data;
size_t size;
public:
Buffer(size_t n) : size(n), data(new int[n]) {}
~Buffer() { delete[] data; }
// 移动构造函数
Buffer(Buffer&& other) noexcept
: data(other.data), size(other.size) {
other.data = nullptr;
other.size = 0;
cout << "移动构造(零拷贝)" << endl;
}
};
int main() {
string s1 = "Hello";
string s2 = move(s1); // 移动语义
cout << "s1: "" << s1 << """ << endl; // s1为空
cout << "s2: "" << s2 << """ << endl;
Buffer a(1000);
Buffer b = move(a); // 移动构造，无拷贝
return 0;
}
```
