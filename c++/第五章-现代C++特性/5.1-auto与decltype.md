# 5.1 auto与decltype

auto（C++11）让编译器根据初始化表达式自动推导变量类型，减少冗余代码，尤其在处理复杂类型（如迭代器、lambda）时非常方便。但 auto 会退化引用和 const 属性，如需保留应使用 auto& 或 const auto&。

decltype（C++11）用于查询表达式的类型，常与 auto 配合用于函数返回类型推导。C++14 引入了 decltype(auto)，它保留了表达式的所有类型修饰。

```cpp
#include <iostream>
#include <vector>
#include <map>
using namespace std;
int main() {
auto a = 10;        // int
auto b = 3.14;      // double
auto c = "hello";   // const char*
// 简化复杂类型
map<string, vector<int>> data;
data["scores"] = {90, 85, 92};
for (const auto& pair : data) {
for (auto score : pair.second)
cout << score << " ";
}
cout << endl;
// decltype 获取类型
decltype(a) d = 20; // d 是 int
return 0;
}
```
