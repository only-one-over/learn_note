# 5.3 Lambda表达式

Lambda 表达式（C++11）是定义匿名函数对象的简洁语法。基本形式为 [捕获列表](参数列表) -> 返回类型 { 函数体 }。

捕获列表决定了 Lambda 如何访问外部变量：值捕获（[x]拷贝值）、引用捕获（[&x]引用）、全部值捕获（[=]）、全部引用捕获（[&]）和混合捕获。Lambda 在 STL 算法中广泛使用，替代了传统的函数对象和函数指针。

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;
int main() {
vector<int> vec = {5, 2, 8, 1, 9, 3, 7};
// Lambda 与 sort
sort(vec.begin(), vec.end(), [](int a, int b) {
return a > b; // 降序
});
// Lambda 与 count_if
int cnt = count_if(vec.begin(), vec.end(),
[](int n) { return n % 2 == 0; });
cout << "偶数个数: " << cnt << endl;
// Lambda 捕获
int threshold = 5;
auto above = [threshold](int n) { return n > threshold; };
cnt = count_if(vec.begin(), vec.end(), above);
cout << "大于" << threshold << "的个数: " << cnt << endl;
return 0;
}
```
