# 5.5 其他现代特性

constexpr（C++11/14）

constexpr 声明的变量和函数可以在编译期求值。constexpr 函数在参数为编译期常量时在编译期执行，否则在运行期执行。

结构化绑定（C++17）

允许用 auto [a, b, c] 的语法一次性解构 pair、tuple、数组或结构体。在遍历 map 时非常方便。

std::optional 与 std::variant（C++17）

optional 表示一个值可能存在也可能不存在。variant 是类型安全的联合体，可以存储多种类型中的一种。它们比裸指针和 union 更安全。

```cpp
#include <iostream>
#include <optional>
#include <tuple>
#include <map>
using namespace std;
constexpr int factorial(int n) {
return n <= 1 ? 1 : n * factorial(n - 1);
}
tuple<int, double, string> getData() {
return {1, 3.14, "Hello"};
}
int main() {
constexpr int f5 = factorial(5);
cout << "5! = " << f5 << endl;
// 结构化绑定
auto [id, val, msg] = getData();
cout << id << ", " << val << ", " << msg << endl;
// map遍历
map<string, int> m = {{"Alice", 90}, {"Bob", 85}};
for (const auto& [name, score] : m)
cout << name << ": " << score << endl;
// optional
optional<int> result = 42;
cout << "值: " << result.value_or(-1) << endl;
return 0;
}
```
