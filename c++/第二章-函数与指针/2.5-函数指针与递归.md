# 2.5 函数指针与递归

函数指针是指向函数的指针变量，可以像普通变量一样传递和存储。通过函数指针可以实现回调机制：将一个函数作为参数传给另一个函数，由后者在适当的时候调用它。

递归是函数直接或间接调用自身的编程技巧。递归必须包含两个要素：基准情况（base case，直接返回不再递归）和递归步骤（将问题分解为更小的子问题）。递归代码简洁优雅，但每次递归调用都会在栈上分配新的栈帧，过深的递归可能导致栈溢出。

```cpp
#include <iostream>
#include <algorithm>
#include <vector>
using namespace std;
// 回调函数
bool desc(int a, int b) { return a > b; }
// 递归: 阶乘
long long factorial(int n) {
if (n <= 1) return 1;         // 基准情况
return n * factorial(n - 1);  // 递归步骤
}
int main() {
// 函数指针
int (*funcPtr)(int, int);
// 回调: 排序
vector<int> v = {5, 2, 8, 1, 9};
sort(v.begin(), v.end(), desc); // 传入回调函数
for (int x : v) cout << x << " ";
cout << endl;
// 递归
cout << "5! = " << factorial(5) << endl; // 120
cout << "10! = " << factorial(10) << endl; // 3628800
return 0;
}
```
