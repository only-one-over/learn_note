# 2.3 指针详解

指针是存储内存地址的变量。它是 C++ 最强大也最危险的特性之一。声明指针时使用 *（如 int* ptr），获取变量地址使用 &（如 &num），通过指针访问值使用解引用 *（如 *ptr）。

指针和数组关系密切：数组名本质上是首元素的地址，指针可以通过算术运算（+、-、++、--）遍历数组。const 与指针的组合有三种形式：指向常量的指针（const int* p）不能通过指针修改值但可以改变指向；常量指针（int* const p）不能改变指向但可以修改值。C++11 推荐使用 nullptr 代替 NULL。

```cpp
#include <iostream>
using namespace std;
int main() {
int num = 42;
int* ptr = &num;  // ptr 存储 num 的地址
cout << "num的值: " << num << endl;
cout << "num的地址: " << &num << endl;
cout << "ptr的值: " << ptr << endl;
cout << "*ptr解引用: " << *ptr << endl;
*ptr = 100;  // 通过指针修改值
cout << "修改后num: " << num << endl;
// 指针与数组
int arr[] = {10, 20, 30, 40, 50};
int* p = arr;  // 数组名即首元素地址
for (int i = 0; i < 5; i++)
cout << *(p + i) << " "; // 指针算术
cout << endl;
// nullptr (C++11)
int* nullPtr = nullptr;
cout << "空指针: " << (nullPtr == nullptr ? "是" : "否") << endl;
return 0;
}
```
