# 2.2 参数传递方式

C++ 有三种参数传递方式，理解它们的区别是写出正确、高效代码的关键。

值传递（Pass by Value）

函数接收的是实参的副本。在函数内修改形参不会影响实参。适用于不需要修改原始数据且数据量较小的场景。缺点是对大型对象会产生拷贝开销。

引用传递（Pass by Reference）

函数接收的是实参的别名（通过 & 声明）。在函数内修改形参会直接修改实参。const 引用（const T&）是只读别名，既避免了拷贝又防止意外修改，是传递大型只读参数的最佳实践。

指针传递（Pass by Pointer）

函数接收的是实参的地址（通过 * 声明）。通过解引用（*ptr）可以修改实参。指针传递可以传递 nullptr 表示无值，这是引用做不到的。现代 C++ 中优先使用引用。

```cpp
#include <iostream>
#include <string>
using namespace std;
// 值传递 - 不影响原值
void passByValue(int x) { x = 100; }
// 引用传递 - 直接修改原值
void passByRef(int& x) { x = 100; }
// 指针传递 - 通过地址修改原值
void passByPtr(int* x) { *x = 100; }
// const引用 - 避免拷贝且防止修改
void printStr(const string& s) {
cout << s << endl;
// s = "new"; // 错误: 不能修改const引用
}
int main() {
int a = 10;
passByValue(a);  cout << "值传递后: " << a << endl; // 10 (不变)
passByRef(a);    cout << "引用传递后: " << a << endl; // 100
passByPtr(&a);   cout << "指针传递后: " << a << endl; // 100
return 0;
}
```
