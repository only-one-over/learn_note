# 2.1 函数基础

函数是将一段逻辑封装起来、可以重复调用的代码单元。良好的函数设计是模块化编程的基础。定义函数时需要指定返回类型、函数名和参数列表。函数声明（原型）告诉编译器函数的存在，使得函数可以在定义之前被调用。

函数重载允许同名函数拥有不同的参数列表（参数类型或数量不同），编译器根据调用时传入的实参类型自动选择匹配的版本。默认参数允许在函数声明中为参数指定默认值，调用时可以省略这些参数。默认参数必须从右向左连续设置。

```cpp
#include <iostream>
#include <string>
using namespace std;
// 函数重载
int add(int a, int b) { return a + b; }
double add(double a, double b) { return a + b; }
int add(int a, int b, int c) { return a + b + c; }
// 默认参数（从右向左）
void greet(string name, int age = 18) {
cout << name << " 今年 " << age << " 岁" << endl;
}
int main() {
cout << add(1, 2) << endl;       // 调用 int 版本
cout << add(1.5, 2.5) << endl;   // 调用 double 版本
cout << add(1, 2, 3) << endl;    // 调用三参数版本
greet("张三");      // age 使用默认值 18
greet("李四", 25);  // age 使用传入值 25
return 0;
}
```
