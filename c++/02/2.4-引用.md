# 2.4 引用

引用是已存在变量的别名，声明时必须初始化（如 int& ref = num），一旦绑定不能再重新绑定到其他变量。引用和被引用变量共享同一块内存地址。

引用与指针的关键区别：引用不能为空（必须绑定到一个有效变量），不能重新绑定，使用时无需解引用（语法更简洁）。引用的主要用途包括：作为函数参数避免拷贝开销、作为函数返回值允许链式调用、用于运算符重载。

```cpp
#include <iostream>
using namespace std;
int arr[] = {1, 2, 3, 4, 5};
// 引用作为返回值 - 可以作为左值
int& getElement(int index) { return arr[index]; }
int main() {
int num = 10;
int& ref = num;  // ref 是 num 的别名
ref = 20;        // 修改 ref 就是修改 num
cout << "num = " << num << endl; // 20
// 引用返回值作为左值
getElement(2) = 100;
cout << "arr[2] = " << arr[2] << endl; // 100
return 0;
}
```
