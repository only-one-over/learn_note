# 4.3 STL常用算法

STL 算法库提供了 100 多个通用算法，通过迭代器与容器解耦。常用算法包括：排序（sort）、查找（find、binary_search）、变换（transform）、统计（count、accumulate）、复制（copy）和修改（replace、remove、reverse）。

大多数算法接受一对迭代器表示操作范围 [begin, end)。许多算法可以接受自定义的谓词（predicate）函数来定制行为。remove 算法只做逻辑删除，需要配合 erase 使用（即 remove-erase 惯用法）才能真正从容器中移除元素。

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <numeric>
using namespace std;
int main() {
vector<int> vec = {5, 2, 8, 1, 9, 3};
// 排序
sort(vec.begin(), vec.end());
sort(vec.begin(), vec.end(), greater<int>());
// 查找
auto it = find(vec.begin(), vec.end(), 8);
if (it != vec.end()) cout << "找到8" << endl;
// 计数
int cnt = count_if(vec.begin(), vec.end(),
[](int n) { return n > 5; });
cout << "大于5的个数: " << cnt << endl;
// 求和
int sum = accumulate(vec.begin(), vec.end(), 0);
cout << "总和: " << sum << endl;
// remove-erase 惯用法
vec.erase(remove(vec.begin(), vec.end(), 8), vec.end());
return 0;
}
```
