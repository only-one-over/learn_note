# 4.4 模板

模板是 C++ 实现泛型编程的机制，允许编写与类型无关的代码。函数模板定义了一族函数，编译器在调用时根据实参类型自动生成对应的函数版本。类模板则定义了一族类。

C++11 引入了可变参模板（template<typename... Args>），C++17 引入了折叠表达式（(args + ...)），使模板可以处理任意数量的参数。模板特化允许为特定类型提供定制实现。

```cpp
#include <iostream>
#include <string>
using namespace std;
// 函数模板
template<typename T>
T maximum(T a, T b) { return (a > b) ? a : b; }
// 类模板
template<typename T, int Size>
class Stack {
T data[Size];
int top = -1;
public:
void push(const T& val) { if (top < Size-1) data[++top] = val; }
T pop() { return top >= 0 ? data[top--] : T(); }
bool empty() const { return top < 0; }
};
// 折叠表达式 (C++17)
template<typename... Args>
auto sumAll(Args... args) { return (args + ...); }
int main() {
cout << maximum(3, 5) << endl;        // int版本
cout << maximum(3.14, 2.72) << endl;  // double版本
Stack<int, 5> stk;
stk.push(10); stk.push(20);
while (!stk.empty()) cout << stk.pop() << " ";
cout << endl;
cout << sumAll(1, 2, 3, 4, 5) << endl; // 15
return 0;
}
```
