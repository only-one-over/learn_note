# 4.1 STL容器

STL（标准模板库）容器是预先实现的数据结构，分为三大类：序列容器（vector、list、deque、array）按插入顺序存储元素；关联容器（map、set、multimap、multiset）按键自动排序存储；容器适配器（stack、queue、priority_queue）提供特定接口。

vector 是最常用的容器，底层是动态数组，支持随机访问（O(1)），尾部插入/删除高效。list 是双向链表，任意位置插入/删除 O(1)。map 是红黑树实现的键值对容器，插入/查找/删除 O(log n)。priority_queue 是优先级队列，默认大顶堆。

```cpp
#include <iostream>
#include <vector>
#include <map>
#include <set>
#include <stack>
#include <queue>
using namespace std;
int main() {
// vector - 动态数组
vector<int> vec = {1, 2, 3};
vec.push_back(4);
vec[0] = 10;
for (int v : vec) cout << v << " ";
cout << endl;
// map - 有序键值对
map<string, int> scores;
scores["张三"] = 90;
scores["李四"] = 85;
for (auto& p : scores)
cout << p.first << ": " << p.second << endl;
// set - 有序不重复集合
set<int> s = {3, 1, 4, 1, 5};
for (int v : s) cout << v << " ";
cout << endl;
// stack - 栈
stack<int> stk;
stk.push(1); stk.push(2);
cout << "栈顶: " << stk.top() << endl;
// priority_queue - 优先队列(大顶堆)
priority_queue<int> pq;
pq.push(3); pq.push(1); pq.push(4);
cout << "最大值: " << pq.top() << endl;
return 0;
}
```
