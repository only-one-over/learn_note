# 1.4 流程控制

流程控制语句决定了程序的执行路径。C++ 提供三种基本结构：顺序结构（从上到下依次执行）、选择结构（根据条件选择不同路径）和循环结构（重复执行某段代码）。

选择结构包括 if-else 语句和 switch 语句。if-else 适合条件较少或条件为范围判断的场景；switch 适合对单个变量进行多值匹配的场景，注意每个 case 分支末尾需要 break 防止穿透。循环结构包括 for、while 和 do-while。C++11 引入的范围 for 循环（for (auto x : container)）可以简洁地遍历容器中的所有元素。break 用于提前跳出循环，continue 用于跳过本次迭代。

```cpp
#include <iostream>
#include <vector>
using namespace std;
int main() {
// if-else
int score = 85;
if (score >= 90) cout << "优秀" << endl;
else if (score >= 80) cout << "良好" << endl;
else cout << "其他" << endl;
// switch
char grade = 'B';
switch (grade) {
case 'A': cout << "优秀" << endl; break;
case 'B': cout << "良好" << endl; break;
default:  cout << "其他" << endl;
}
// for 循环
for (int i = 0; i < 5; i++) cout << i << " ";
cout << endl;
// 范围 for (C++11)
int arr[] = {1, 2, 3, 4, 5};
for (int num : arr) cout << num << " ";
cout << endl;
// while + break/continue
int n = 0;
while (n < 10) {
n++;
if (n == 3) continue; // 跳过3
if (n == 7) break;    // 到7停止
cout << n << " ";
}
return 0;
}
```
