# 6.4 命名空间

命名空间用于防止名称冲突，将代码组织在逻辑分组中。使用 namespace 关键字定义命名空间，通过 :: 作用域解析符访问其中的成员。using 声明引入单个名称，using 指令引入整个命名空间。匿名命名空间中的内容只在当前翻译单元可见。

```cpp
#include <iostream>
using namespace std;
namespace Math {
const double PI = 3.14159;
double square(double x) { return x * x; }
namespace Geometry {
double circleArea(double r) { return PI * r * r; }
}
}
int main() {
cout << Math::PI << endl;
cout << Math::square(5) << endl;
cout << Math::Geometry::circleArea(3) << endl;
using namespace Math::Geometry;
cout << circleArea(3) << endl;
return 0;
}
```
