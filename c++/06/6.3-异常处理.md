# 6.3 异常处理

异常处理机制用于处理程序运行时的错误，使错误处理代码与正常逻辑分离。throw 抛出异常，try-catch 捕获并处理异常。C++ 标准库定义了异常类层次结构：exception 是基类，其下有 runtime_error、logic_error 等派生类。

异常安全有三个级别：基本保证（无资源泄漏）、强保证（操作失败时回滚到操作前状态）、不抛出保证（noexcept，承诺不抛出异常）。

```cpp
#include <iostream>
#include <stdexcept>
using namespace std;
double divide(double a, double b) {
if (b == 0) throw runtime_error("除数不能为零");
return a / b;
}
int main() {
try {
cout << divide(10, 2) << endl;
cout << divide(10, 0) << endl;
} catch (const runtime_error& e) {
cout << "运行时错误: " << e.what() << endl;
} catch (const exception& e) {
cout << "其他异常: " << e.what() << endl;
} catch (...) {
cout << "未知异常" << endl;
}
return 0;
}
```
