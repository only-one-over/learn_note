# 6.2 RAII原则

RAII（Resource Acquisition Is Initialization，资源获取即初始化）是 C++ 最核心的编程范式之一。其核心思想是：将资源的生命周期绑定到对象的生命周期上。在构造函数中获取资源，在析构函数中释放资源。

RAII 的优势：无需手动释放资源、异常安全（异常发生时析构函数仍会被调用）、代码更简洁。标准库中的智能指针、lock_guard、fstream 等都是 RAII 的典型实现。

```cpp
#include <iostream>
#include <fstream>
#include <mutex>
using namespace std;
// RAII 文件管理
class FileHandler {
ofstream file;
public:
FileHandler(const string& path) {
file.open(path);
cout << "文件已打开" << endl;
}
~FileHandler() {
if (file.is_open()) {
file.close();
cout << "文件已关闭" << endl;
}
}
void write(const string& content) { file << content; }
};
int main() {
mutex mtx;
{
lock_guard<mutex> lock(mtx);
cout << "临界区操作" << endl;
} // 离开作用域，自动释放锁
FileHandler fh("test.txt");
fh.write("Hello RAII!");
return 0;
}
```
