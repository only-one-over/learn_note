# 1.1 数据类型

C++ 程序中的一切数据都有明确的类型。类型决定了数据占用的内存大小、能表示的值的范围，以及可以对该数据执行的操作。C++ 的类型系统分为两大类：基本类型（由语言内置）和复合类型（由基本类型组合而成）。

基本数据类型包括整型（int、short、long、long long）、字符型（char、wchar_t、char16_t、char32_t）、浮点型（float、double、long double）和布尔型（bool）。不同平台下各类型的字节数可能不同，但 C++ 标准规定了最小范围。例如，int 至少为 16 位，long long 至少为 64 位。选择数据类型时应考虑：需要表示的数值范围、精度要求、内存占用和性能影响。

```cpp
#include <iostream>
#include <climits>
using namespace std;
int main() {
int age = 25;
double pi = 3.14159265358979;
char grade = 'A';
bool isPassed = true;
cout << "年龄: " << age << endl;
cout << "PI: " << pi << endl;
cout << "等级: " << grade << endl;
cout << "是否通过: " << isPassed << endl;
// 查看类型大小
cout << "int 大小: " << sizeof(int) << " 字节" << endl;
cout << "double 大小: " << sizeof(double) << " 字节" << endl;
cout << "int 最大值: " << INT_MAX << endl;
return 0;
}
```
