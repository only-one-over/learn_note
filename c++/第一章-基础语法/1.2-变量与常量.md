# 1.2 变量与常量

变量是程序中用于存储数据的命名内存空间。声明变量时需要指定类型，编译器据此分配合适数量的内存。C++ 支持多种初始化方式：传统的等号初始化 int a = 10;、括号初始化 int b(20); 以及 C++11 引入的列表初始化 int c{30}。列表初始化的优势是禁止窄化转换（如 double 到 int 的隐式截断），更加安全。

常量是值不可修改的量。const 关键字声明运行时常量，constexpr（C++11）声明编译时常量。constexpr 的值在编译期即可确定，编译器可以进行更积极的优化。变量的作用域决定了它的可见范围：全局变量在整个文件中可见，局部变量仅在声明所在的函数或代码块中可见。

```cpp
#include <iostream>
using namespace std;
int globalVar = 100; // 全局变量
int main() {
int a = 10;          // 传统初始化
int b(20);           // 括号初始化
int c{30};           // 列表初始化(C++11)
auto d = 40;         // auto推导(C++11)
const double PI = 3.14159;      // 运行时常量
constexpr int MAX = 100;        // 编译时常量
// 作用域演示
{
int blockVar = 300; // 仅在此块内可见
cout << blockVar << endl;
}
// blockVar 在此处不可访问
cout << globalVar << endl; // 全局变量随处可访问
return 0;
}
```
