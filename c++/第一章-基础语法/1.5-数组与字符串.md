# 1.5 数组与字符串

数组是存储相同类型元素的连续内存区域。一维数组的声明格式为 type name[size]，元素通过下标（从 0 开始）访问。二维数组可以看作数组的数组，常用于表示矩阵或表格。C++11 允许使用列表初始化数组，且可以省略大小让编译器自动推导。

C++ 中有两种字符串表示方式：C 风格字符串（以空字符 '\0' 结尾的 char 数组）和 C++ 标准库的 string 类。string 类封装了内存管理，支持拼接、查找、子串提取等操作，使用更加安全和方便。在实际开发中应优先使用 string 类。

```cpp
#include <iostream>
#include <string>
using namespace std;
int main() {
// 一维数组
int arr[] = {10, 20, 30, 40, 50};
for (int i = 0; i < 5; i++)
cout << arr[i] << " ";
cout << endl;
// 二维数组
int matrix[2][3] = {{1,2,3}, {4,5,6}};
// C++ string 类
string s1 = "Hello";
string s2 = "World";
string s3 = s1 + " " + s2; // 拼接
cout << s3 << endl;         // Hello World
cout << "长度: " << s3.length() << endl;  // 11
cout << "子串: " << s3.substr(0, 5) << endl; // Hello
cout << "查找: " << s3.find("World") << endl; // 6
return 0;
}
```
