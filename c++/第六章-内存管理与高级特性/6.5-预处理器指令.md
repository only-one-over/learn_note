# 6.5 预处理器指令

预处理器在编译之前对源代码进行文本替换和处理。主要指令包括：#define 定义宏、#include 包含头文件、#ifdef/#ifndef/#endif 条件编译。宏定义是简单的文本替换，没有类型检查，现代 C++ 中推荐用 const/constexpr 和 inline 函数替代。条件编译广泛用于跨平台代码和头文件保护。

```cpp
#include <iostream>
using namespace std;
#define PI 3.14159
#define SQUARE(x) ((x) * (x))
#define DEBUG
#ifdef DEBUG
#define LOG(msg) cout << "[DEBUG] " << msg << endl
#else
#define LOG(msg)
#endif
#ifndef MY_MODULE_H
#define MY_MODULE_H
#endif
int main() {
cout << "PI = " << PI << endl;
cout << "SQUARE(5) = " << SQUARE(5) << endl;
LOG("程序开始");
return 0;
}
```
