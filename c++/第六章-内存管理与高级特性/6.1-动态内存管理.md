# 6.1 动态内存管理

C++ 程序的内存分为栈（stack）和堆（heap）。栈内存由编译器自动管理，速度快但空间有限。堆内存由程序员手动管理，通过 new/delete 分配和释放。

new 表达式在堆上分配内存并调用构造函数初始化对象，delete 调用析构函数并释放内存。new[] 分配数组时必须用 delete[] 释放。内存泄漏是指分配的堆内存未被释放。现代 C++ 中应使用智能指针代替裸 new/delete。

```cpp
#include <iostream>
#include <memory>
using namespace std;
int main() {
// 裸指针方式(不推荐)
int* p = new int(42);
cout << *p << endl;
delete p;
// 数组
int* arr = new int[5]{1, 2, 3, 4, 5};
delete[] arr;
// 智能指针方式(推荐)
auto sp = make_unique<int>(42);
auto arr2 = make_unique<int[]>(5);
arr2[0] = 100;
// 离开作用域自动释放
return 0;
}
```
